# Value Objects

All Value Objects are:

- Immutable
- Self-validating
- Comparable by value
- Framework independent

## Identity VOs
- UserId
- ClientId
- SessionId

## Security VOs
- Email (normalized)
- PasswordHash
- PlainPassword
- TokenId

## OAuth VOs
- Scope
- ScopeSet
- RedirectUri

## Shared VOs
- Timestamp
